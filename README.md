\#Kitaplik Yonetim sistemi

C# Form ile geliştirilmiş temel bir kutuphane takip uygulamasidir.



\##Ozellikler

* Kitap Ekleme
* Kitap Arama
* Kitap Listeleme (ListBox ve DataGridView)
* Kitap Guncelleme
* Kitap Silme
* SQL Server Veritabani Entegrasyonu



\## Kullanim

Projeyi Visual Studio ile acip `App.config` dosyasindaki baglanti adresini kendi veritabaniniza gore guncelleyerek calıstirabilirsiniz.
